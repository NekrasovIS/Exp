# Задача 1: Демонстрация экрана (screen capture)

## Статус

In progress

## Что делает

Добавляет захват содержимого экрана (или отдельного окна) как ещё один
источник видео в DeviceHub — по аналогии с камерой, но источником кадров
служит экран, а не веб-камера.

## Зачем

Второй источник видео наравне с аудио/микрофоном/камерой — превращает
DeviceHub в инструмент для демонстрации экрана (скринкасты, шаринг
экрана), а не только проверки устройств ввода.

## Как использовать

- В UI появляется список доступных экранов/окон для захвата (аналогично
  комбобоксу камер).
- Кнопка Start/Stop запускает/останавливает захват.
- Предпросмотр захваченного экрана отображается в `QVideoWidget`,
  аналогично превью камеры.

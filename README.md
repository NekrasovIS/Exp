# DeviceHub

[![CI](https://github.com/NekrasovIS/Exp/actions/workflows/ci.yml/badge.svg)](https://github.com/NekrasovIS/Exp/actions/workflows/ci.yml)

Десктопное Qt6-приложение для работы с устройствами ОС: аудио-выход,
микрофон, камера. Начиналось как демонстрация доступа к железу через
Qt Multimedia; развивается в сторону клиент-серверного инструмента с
подключением по web-ссылке (см. [CLAUDE.md](CLAUDE.md)). Пока
пользователь не авторизован, единственное видимое окно — `LoginWindow`
(вход по одноразовому коду или по паролю, там же регистрация); главное
окно открывается только после успешного входа.

Раскладка главного окна — многоколоночная (акцент остаётся зелёным
градиентом, `src/ui/Theme.h`): слева сайдбар из двух колонок — узкая
иконочная полоса сообществ (72px; кнопка «Friends» сверху — issue #187,
Фаза 3, переключает в режим друзей/личных сообщений, см.
[docs/FEATURES.md](docs/FEATURES.md); круглые
аватарки с первой буквой названия — только те сообщества, в которых
уже состоит вошедший пользователь; «+» снизу открывает окно
подключения — вступить по коду приглашения или создать новое, —
правый клик по аватарке копирует код приглашения, для владельца ещё и
перевыпускает его/переименовывает/удаляет) и список каналов выбранного
сообщества (240px, «+» создаёт канал, правый клик — переименовать/
удалить, названия с префиксом «#»); клик по каналу открывает чат в
центре. Справа от чата — список участников выбранного сообщества
(`MemberListPanel`, 240px; сворачивается и разворачивается иконкой в
правом углу шапки канала, issue #184). В режиме друзей та же вторая
колонка показывает список друзей и входящих заявок вместо каналов, а
основная область — упрощённый диалог личных сообщений вместо чата
канала. Сообщение отправляется через единый скруглённый композер
(иконка «+» слева для вложений, поле ввода без своей рамки, зелёная
стрелка справа вместо подписанной кнопки «Send»). Футер снизу —
профиль (клик по аватару открывает меню Edit Profile/Sign Out) и
настройки устройств (Audio Output, Microphone, Camera, Screen Capture)
в отдельном диалоге.

  приложения (устройства, чаты, звонки, шифрование, роли и т.д.).

- [docs/services/](docs/services/) — три независимых backend-сервиса,
  по файлу на каждый:

  [auth-service](docs/services/auth-service.md),
  [chat-service](docs/services/chat-service.md).
- [docs/DESKTOP_INTEGRATION.md](docs/DESKTOP_INTEGRATION.md) — как
  десктопный клиент использует эти три сервиса изнутри (авторизация,
  чат/звонки/шифрование на стороне DeviceHub).
- [docs/WEB_CLIENTS.md](docs/WEB_CLIENTS.md) — веб/мобильный монорепо
  (`packages/`, `apps/web`, issue #219).

  историей прогонов CI.

- [CLAUDE.md](CLAUDE.md) — стиль кода, структура проекта, конвенции по
